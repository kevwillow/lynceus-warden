How to read this
  • There is no score, and that is deliberate. Sensor uptime is not recorded, so missing data cannot distinguish downtime, a quiet device, and a device that was not there. No confidence number would be defensible.
  • “Co-observed” means both were logged within {{ proximity_seconds }}s of each other at one location. Nothing more.
  • Run boundaries are inferred from observations, never arrival and departure. Intermittent logging inflates run counts.
  • Randomized MACs cannot reliably be merged into one device, so one phone may appear as many rows, or vanish between runs.
  • A MAC is not a person. Mesh nodes, access-point radios and hotspots co-occur naturally and constantly.
  • Probe SSIDs are unverified metadata a device broadcast. They corroborate; they rank nothing.
